# Privacy

Darken It is a Chrome extension that applies a dimming effect to websites when you enable it.

## Information stored

Darken It stores the website domain, the dimming level you chose, and whether the effect is enabled for that domain. This information is saved in Chrome's local extension storage on your device.

## Information sent to anyone

Darken It does not send website content, browsing history, or saved settings to the developer or to a server. The extension contains no analytics or advertising code.

## Website access

The extension needs permission to access websites so it can apply its visual effect. It uses the current website's domain to find the setting you saved for that site. It does not need to read page text or collect information from forms.

## Removing the extension

Chrome's local extension data may be deleted when you remove Darken It. You can also remove the saved settings by removing the extension from `chrome://extensions`.

## Contact

For privacy questions, please open an issue in the [Darken It GitHub repository](https://github.com/Quick-Eyed-Sky/DarkenIt/issues).
